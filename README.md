# cpp-logger

A lightweight configurable logging library written in modern C++20.

## Features

- [ ] Log levels
- [ ] Console output
- [ ] File output
- [ ] Timestamped messages
- [ ] Log filtering
- [ ] File rotation
- [ ] Unit tests
- [ ] Continuous Integration

## Requirements

- C++20 compatible compiler
- CMake 3.20 or newer

## Build

```bash
cmake -S . -B build
cmake --build build
